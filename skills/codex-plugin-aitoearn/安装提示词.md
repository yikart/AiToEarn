# AiToEarn Codex 插件安装指令

请帮我安装本目录中的 AiToEarn Codex 插件。技能与 MCP 连接必须都完成，不能只安装技能就宣称成功。

1. 如果以前安装或配置过 AiToEarn，先卸载旧 `aitoearn` 插件，并删除旧的 AiToEarn MCP 条目；只处理 `aitoearn`、`aitoearn-cn` 或指向旧 AiToEarn 地址的条目，不要删除其他 MCP 服务。
2. 确认插件包目录；不要从包外寻找配置或旧凭证。
3. 使用包内现成的 `.mcp.json`；它预设中国版 server `aitoearn-cn` 与 `https://aitoearn.cn/api/ai/agent/mcp`。不得重命名、重新生成或添加认证请求头、环境变量及任何静态凭证。
4. 按 Codex 的本地 marketplace 流程安装并启用插件。
5. **无需注册全局 MCP**（需要手动注册全局 MCP 的只有 Trae）：Codex 会自动加载插件内 `.mcp.json` 声明的 server；使用国际版时把 `.mcp.json` 的 server 名改为 `aitoearn`、URL 改为 `https://aitoearn.ai/api/ai/agent/mcp`。两个版本只保留一个。必须完成 OAuth 登录：桌面版在 设置 → 插件 → MCP 对 AiToEarn server 点「进行身份验证」（中国版先把连接类型改为「动态客户端注册 (DCR)」；国际版直接认证，已实测无需 DCR）；命令行等价：`codex mcp login aitoearn-cn --oauth-client-registration dcr`（中国版，dcr 参数必须保留：默认登录方式依赖服务端访问 chatgpt.com，中国版服务端不可达，授权页会报"应用配置错误"）或 `codex mcp login aitoearn`（国际版）。
6. 如果用户使用 Codex 桌面版，**明确提示用户去 MCP 连接认证**：在 设置 → 插件 → MCP 中找到对应 server，中国版把连接类型从「自动」改为「动态客户端注册 (DCR)」再点「进行身份验证」完成授权，国际版直接点「进行身份验证」即可（已实测无需 DCR）；这与上一步的命令行参数等价，二选一即可。若用户改在桌面版手动添加 MCP（连接至自定义 MCP），必须提醒：**类型选「流式 HTTP」**（默认 STDIO 连不上），只填名称与 URL。无论哪种方式，都必须让用户知道需要主动完成这一步，不能装完就结束。
7. 运行 `codex mcp list`，确认 AiToEarn server 显示为 `enabled`，然后完全退出并重启 Codex。
8. 新会话中发送「列出可用的发布渠道」验证。只有工具实际出现并能返回渠道列表，才能报告安装完成。

若没有 OAuth 授权入口、授权失败或工具未出现，明确说明 MCP 尚未连接，保留错误信息并停止；绝不改用旧的静态请求头方案。

用户不懂编程：所有文件操作由你完成。遇到权限拦截，先使用当前应用的授权机制；没有权限就说明无法完成安装并建议使用该平台的官方安装方式。
