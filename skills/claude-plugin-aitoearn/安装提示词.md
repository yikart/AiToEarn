# AiToEarn Claude Code 插件 安装指令

请帮我安装 AiToEarn（Claude Code 插件）。按下面步骤执行：

## 如何定位插件包

- 如果你是通过文件路径读取到这份文档的：插件包目录就是本文件所在的目录，直接使用它，不要去找其他路径。
- 如果你是在对话框里看到这段文字的：插件包默认位于本仓库 `skills/claude-plugin-aitoearn` 目录（如果 skills 文件夹被移动或单独下载过，以实际路径为准）；如果该目录不存在，先向我询问实际路径再继续，不要使用其他来源的文件。

## 开始前检查

开始执行前先确认你能读写我的用户主目录（安装会写入 ~/.codex、~/.qwenworkcn、~/.dsh、~/.trae-cn、Library/Application Support 等位置，按本平台的步骤需要哪些就确认哪些）。如果确认没有权限，现在就告诉我，不要做到一半才失败。

第 0 步：请提供你的 AiToEarn API Key（获取方式：登录 aitoearn.cn → 设置 → API Key → 创建；如果给的是国际站 aitoearn.ai 的 Key 也请说明）。

## 安装步骤

技能（SKILL.md）与 MCP 连接两部分都必须完成，缺一不可；只完成一半不算安装完成。

1. 读取包里的 `.mcp.json.tpl`，把我提供的 Key 填入 `__AITOEARN_KEY__`；国内站 Key 保持 URL 为 `https://aitoearn.cn/api/ai/agent/mcp`、server 名 `aitoearn-cn`，国际站 Key 则换成 `https://aitoearn.ai/api/ai/agent/mcp`、server 名填 `aitoearn`；以结果另存为包目录下的 `.mcp.json`，并校验它是合法 JSON。
2. 优先执行 `claude plugin marketplace add <插件包目录>`，再 `claude plugin install aitoearn@<marketplace 名称>`。
3. 如果本机没有 `claude` CLI 或命令失败，改为提醒我把插件包目录复制到 `~/.claude/plugins/`，并在 Claude Code 设置里启用。

## 安装完成后

提醒我必须完全退出并重新打开 Claude Code（不是关闭窗口），重启后新会话才会加载插件、技能与 MCP 连接。

## 验证（这一步同时检验 MCP 是否配好）

在新会话里发送「列出可用的发布渠道」：

- 能正常返回渠道列表 → 技能与 MCP 都安装成功；
- 如果提示没有相关工具、找不到渠道或连接失败 → 说明 MCP 没配好，必须明确告诉我“MCP 还没配置”，然后按下面「MCP 手动兜底」处理，配好后让我再次验证；绝对不允许只装技能就告诉我安装完成。

## MCP 手动兜底（自动配置失败时）

1. 检查插件包目录下 `.mcp.json` 是否存在、Key 是否正确；不对就按 `.mcp.json.tpl` 重新生成。
2. 执行 `claude plugin list`（或查看 `~/.claude/plugins/`）确认本插件已安装并启用；没有就重新 install。
3. 仍不通：明确告诉我“自动配置没成功”，建议我改用官方「AiToEarn 全平台管理器」安装，或重新按本文件执行一遍。

## 失败处理

- 任何一步失败，立即停止后续操作，用我能看懂的大白话告诉我卡在哪一步、缺什么，不要假装成功。
- 我不懂编程，也几乎不会用终端：**绝对不要给我终端命令、脚本或代码让我自己执行**。所有文件操作必须由你通过你自己的工具完成。
- 遇到系统权限拦截（例如 Operation not permitted / 权限被拒绝）时：先通过你所在应用自带的授权机制向我申请对应目录的访问权限，并提醒我在弹出的授权窗口里点「允许」；如果该应用没有授权机制、确实访问不了那些目录，直接明确告诉我“当前应用无法完成安装”，告诉我应该换用什么方式（例如改用官方安装器或该平台内置的插件市场），然后停止。
- 需要我在客户端里手动点击的步骤，给我一步一步的点击指引：点哪个菜单、选哪一项、填什么。
