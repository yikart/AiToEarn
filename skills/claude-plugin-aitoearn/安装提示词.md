# AiToEarn Claude Code 插件安装指令

请安装本目录中的 AiToEarn Claude Code 插件。技能与 MCP 连接缺一不可。

1. 确认插件包目录并读取 `.mcp.json.tpl`。
2. 生成 `.mcp.json`：中国版为 `aitoearn-cn` + `https://aitoearn.cn/api/ai/agent/mcp`；国际版为 `aitoearn` + `https://aitoearn.ai/api/ai/agent/mcp`。不要写入认证请求头、环境变量或静态凭证。
3. 按 Claude Code 的插件安装流程启用本插件并重启客户端。
4. **明确提示用户去 MCP 连接认证**：重启后在 Claude Code 输入 `/mcp` 打开 MCP 面板，选择 AiToEarn server 发起认证，在浏览器完成 OAuth 登录；不要被动等待客户端弹出授权页，也不要向用户索要或保存 API Key。
5. 发送「列出可用的发布渠道」验证，只有实际返回工具结果才可报告成功。

如果客户端没有 OAuth 授权入口、授权未完成或工具没有加载，必须说明“MCP 尚未配置完成”并停止，不能回退到旧鉴权方式。所有文件操作由你完成；无法取得权限时如实说明并建议官方安装入口。
