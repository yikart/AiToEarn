# Executable Handoff to Basic

Use a list/table suitable for task complexity. These are completeness criteria, not mandatory JSON fields or tool parameters:

1. Intent and scope: purpose, plan-only/production, known project, new/append/replace/local edit, binding constraints, assumptions, separate deliverables.
2. Canvas and duration: requested dimensions/aspect ratio and relevant known FPS; strict/approximate budget per deliverable. Reuse current settings or state suitable defaults where unspecified.
3. Sources and preparation: accessible reference, original/derived identity, readiness, evidence provenance/ranges, synchronization, completed/pending processing. Only use actual retrieved IDs.
4. Sequence and layers: source, source in/out or image hold, order, track role, necessary treatment. Include timeline start/end, speed, overlap, and occurrence identity when synchronization/layering requires them. Preserve audio/video associations.
5. Audio/text/connections: supplied assets, audible ranges, requested mixing/fades, verified subtitle text and source timing, editorial titles distinguished from quotations, transitions and required handles. Omit unused categories.
6. Rationale and gaps: evidence for major choices, unresolved dependencies, blocked operations, and next checks. Label the plan conditional until required evidence/assets/capabilities are ready.
7. Acceptance: values to compare with project readback, dependent timing, content/audio checks needing composed preview. Apply basic's gate without treating structural success as audiovisual review.

Independent deliverables need separate project destinations under basic's one-timeline-per-project model and actual environment support. Do not assume multiple timelines inside one project or concatenate independent versions. Resolve ambiguous destinations before writing.

## Example: Exact Accepted Material

User facts: silent video A source 10–14 s at 1x, replay that range at 0.5x, then supplied image B held 3 s. No transitions/music/text. Sources are accessible; content and fitting already approved.

| Occurrence | Source selection | Timeline | Treatment |
| --- | --- | --- | --- |
| A-main | A 10–14 s | 0–4 s | 1x, silent |
| A-replay | A 10–14 s | 4–12 s | 0.5x, silent |
| B-end | B hold 3 s | 12–15 s | Approved fitting |

Duration is 15 s. These are planning values, not proof of application. Basic resolves IDs, translates to supported operations, and reads back ranges, speed, duration, order, and fitting. No new semantic analysis is needed for this exact approved sequence. Selecting an image or choosing an unknown crop would require image-content evidence first.
