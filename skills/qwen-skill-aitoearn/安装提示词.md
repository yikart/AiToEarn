# AiToEarn 千问技能安装指令

请安装本目录的 AiToEarn 技能，并在千问「连接」中建立 OAuth MCP 连接。

1. 安装本目录中的技能，不要复制任何旧配置或凭证。
2. 在「连接」中添加 HTTP MCP：选择中国版 `https://aitoearn.cn/api/ai/agent/mcp` 或国际版 `https://aitoearn.ai/api/ai/agent/mcp`；不要配置认证请求头。
3. 完全重启千问。**明确提示用户去「连接」里认证**：对 AiToEarn 连接点击授权/认证，在浏览器完成 OAuth 登录；然后新建会话发送「列出可用的发布渠道」。

只有工具实际出现并返回渠道列表才能报告完成。没有 OAuth 入口、授权失败或工具缺失时，明确说明 MCP 未连接并停止；不要索取或使用 API Key。
