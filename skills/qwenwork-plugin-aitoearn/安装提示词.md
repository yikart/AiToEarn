# AiToEarn 千问办公插件安装指令

请安装本目录的插件并配置 OAuth MCP 连接。

1. 将插件目录复制到千问办公自定义插件目录并重启客户端。
2. 在「扩展 → 连接器」导入本包 `paste-config.json`；中国版连接 `https://aitoearn.cn/api/ai/agent/mcp`，国际版连接 `https://aitoearn.ai/api/ai/agent/mcp`。导入内容不得补充认证请求头或静态凭证。
3. **明确提示用户去连接器认证**：到「扩展 → 连接器」对 AiToEarn 连接器点击连接/认证，在浏览器完成 OAuth 登录；然后新建任务验证「列出可用的发布渠道」。

只有工具真实可用时才可报告成功。没有 OAuth 入口或授权失败时，明确报告“MCP 尚未配置完成”并停止；不得回退到旧鉴权方式。
