# AiToEarn 千问办公插件 安装指令

请帮我安装 AiToEarn（千问办公插件）。按下面步骤执行：

## 如何定位插件包

- 如果你是通过文件路径读取到这份文档的：插件包目录就是本文件所在的目录，直接使用它，不要去找其他路径。
- 如果你是在对话框里看到这段文字的：插件包默认位于本仓库 `skills/qwenwork-plugin-aitoearn` 目录（如果 skills 文件夹被移动或单独下载过，以实际路径为准）；如果该目录不存在，先向我询问实际路径再继续，不要使用其他来源的文件。

## 开始前检查

开始执行前先确认你能读写我的用户主目录（安装会写入 ~/.codex、~/.qwenworkcn、~/.dsh、~/.trae-cn、Library/Application Support 等位置，按本平台的步骤需要哪些就确认哪些）。如果确认没有权限，现在就告诉我，不要做到一半才失败。

第 0 步：请提供你的 AiToEarn API Key（获取方式：登录 aitoearn.cn → 设置 → API Key → 创建；如果给的是国际站 aitoearn.ai 的 Key 也请说明）。

## 安装步骤

技能（SKILL.md）与 MCP 连接两部分都必须完成，缺一不可；只完成一半不算安装完成。

1. 把插件包目录复制到 `~/.qwenworkcn/plugins-custom/aitoearn`（若已存在先备份再覆盖）。
2. 读取包里的 `paste-config.json`，把 `__AITOEARN_KEY__` 替换为我提供的 Key（国内站 URL 保持 `https://aitoearn.cn/api/ai/agent/mcp`；国际站 Key 则换成 `https://aitoearn.ai/api/ai/agent/mcp`）。
3. 提醒我重启后：打开「扩展 → 专家套件」里的 AiToEarn 全域内容运营；再打开「扩展 → 连接器」→ 右上角「添加」→「导入 JSON」，粘贴第 2 步替换好 Key 的配置并确认。
4. 注意：若千问办公里已有旧的 AiToEarn 连接器，先提醒我在连接器列表里删除它，避免重复。

## 安装完成后

提醒我必须完全退出并重新打开千问办公（不是关闭窗口），重启后新会话才会加载插件、技能与 MCP 连接。

## 验证（这一步同时检验 MCP 是否配好）

重启客户端后，在新会话里发送「列出可用的发布渠道」：

- 能正常返回渠道列表 → 技能与 MCP 都安装成功；
- 如果提示没有相关工具、找不到渠道或连接失败 → 说明 MCP 没配好，必须明确告诉我“MCP 还没配置”，然后按下面「MCP 手动兜底」处理，配好后让我再次验证；绝对不允许只装技能就告诉我安装完成。

## MCP 手动兜底（自动配置失败时）

1. 打开千问办公「扩展 → 连接器」，确认存在名为 `aitoearn-cn` 的连接器且已启用。
2. 没有就手动添加：可以再次「导入 JSON」（把 `paste-config.json` 里的 `__AITOEARN_KEY__` 换成我的 Key 后粘贴），或手动填写：名称 aitoearn-cn、类型 HTTP、地址 `https://aitoearn.cn/api/ai/agent/mcp`、Header `X-Api-Key` = 我的 Key。
3. 添加后新建任务重试。

## 失败处理

- 任何一步失败，立即停止后续操作，用我能看懂的大白话告诉我卡在哪一步、缺什么，不要假装成功。
- 我不懂编程，也几乎不会用终端：**绝对不要给我终端命令、脚本或代码让我自己执行**。所有文件操作必须由你通过你自己的工具完成。
- 遇到系统权限拦截（例如 Operation not permitted / 权限被拒绝）时：先通过你所在应用自带的授权机制向我申请对应目录的访问权限，并提醒我在弹出的授权窗口里点「允许」；如果该应用没有授权机制、确实访问不了那些目录，直接明确告诉我“当前应用无法完成安装”，告诉我应该换用什么方式（例如改用官方安装器或该平台内置的插件市场），然后停止。
- 需要我在客户端里手动点击的步骤，给我一步一步的点击指引：点哪个菜单、选哪一项、填什么。
