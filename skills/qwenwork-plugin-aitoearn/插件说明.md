# 全域内容运营助手（千问办公插件）

由 AiToEarn 全平台管理器安装。插件不替代千问的模型和额度；它增加 AiToEarn 的媒体生产、云剪辑、真实账号发布与 13 个专业子技能。

## 三个关键点

### 1. 和直接使用千问官方 agent 有什么不同

- 增加 AiToEarn MCP：图片、视频、音频、字幕、云剪辑、媒体理解与发布工具；
- 增加任务路由和专业工作流，不需要每次复制长提示词；
- 能读取 AiToEarn 已授权账号与平台实时限制；
- 能从素材生成一路走到成片、发布和任务记录；
- 若千问已手动接入同一个 MCP，底层能力相同，本插件主要多出安装、技能路由和一致性。

### 2. 如何使用

首次使用需添加一次 MCP 连接器（约 20 秒）：

1. 完全退出并重新打开千问办公；
2. 左侧「扩展 → 连接器」→ 右上角「添加」→「导入 JSON」；
3. 粘贴管理器已复制的配置并确认（备份在本目录 `paste-config.json`）；
4. 打开「扩展 → 专家套件」中的 全域内容运营助手；
5. 新建任务，发送「列出可用的发布渠道」验证。

如果「导入 JSON」不可用，改选「手动添加」：名称 `aitoearn-cn`，传输方式 HTTP，URL `https://aitoearn.cn/api/ai/agent/mcp`，请求头 `X-Api-Key: 你的 Key`。国际站则使用 `https://aitoearn.ai/api/ai/agent/mcp`；两站 Key 不通用。

发布前到 AiToEarn 的「我的频道」扫码授权账号。

### 3. 如何收费

- **千问自身套餐/额度**：独立，插件不包含。
- **插件安装**：当前版本没有独立价格、订阅或席位校验，安装不扣 AiToEarn 积分。
- **AiToEarn 服务**：按实际模型和操作从账户扣积分；图片/视频价格由工具目录实时返回。
- **平台广告等站外费用**：不在插件控制范围。

高成本任务先要求「只预览，不发布」，并让 agent 报模型、参数与预计积分。

## 卸载

再次运行 AiToEarn 管理器选择卸载；或删除本目录，并到「扩展 → 连接器」删除名为 `aitoearn-cn` 的连接器。
