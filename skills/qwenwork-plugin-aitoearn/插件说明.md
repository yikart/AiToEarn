# 全域内容运营助手（千问办公插件）

插件为千问办公增加 AiToEarn 的内容生成、媒体处理与多平台发布 MCP 工具，并提供专业任务路由。

首次使用时，在「扩展 → 连接器」导入本包 `paste-config.json`，选择中国版 `https://aitoearn.cn/api/ai/agent/mcp` 或国际版 `https://aitoearn.ai/api/ai/agent/mcp`。连接器必须通过客户端 OAuth 授权，不使用自定义认证请求头或静态凭证。

完成 OAuth 后新建任务发送「列出可用的发布渠道」验证。若没有 OAuth 入口或授权失败，连接不可用，应等待客户端或服务端修复后再试。
