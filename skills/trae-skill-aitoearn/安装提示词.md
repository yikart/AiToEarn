# AiToEarn Trae 技能安装指令

请安装本目录中的 Trae 技能和 MCP 配置。

1. 将技能目录放入 Trae 的技能目录。
2. 将本包 `mcp.json` 的服务器条目合并到 Trae 的既有 MCP 配置；中国版使用 `https://aitoearn.cn/api/ai/agent/mcp`，国际版使用 `https://aitoearn.ai/api/ai/agent/mcp`。不得添加认证请求头或静态凭证。
3. 完全重启 Trae。**明确提示用户去 MCP 连接认证**：到 Trae 的 MCP 设置/连接管理页对 AiToEarn 连接点击连接/认证，在浏览器完成 OAuth 授权；不要被动等待客户端弹出登录窗口。
4. 新建对话发送「列出可用的发布渠道」验证；只有真实返回工具结果才可报告成功。

如果当前 Trae 环境没有 OAuth 授权入口、无法保存或授权失败，明确报告“MCP 尚未配置完成”并停止。不要向用户索要 API Key，也不要改用旧的请求头配置。
