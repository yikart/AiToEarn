# AiToEarn Trae 技能安装指令

请安装本目录中的 Trae 技能和 MCP 配置。

1. 将技能目录放入 Trae 的技能目录（全局 `~/.trae-cn/skills/`，或项目 `<项目>/.trae/skills/`）。
2. 配置 MCP：Trae 不会自动读取技能包内的 `mcp.json`。中国版地址 `https://aitoearn.cn/api/ai/agent/mcp`，国际版 `https://aitoearn.ai/api/ai/agent/mcp`，不得添加认证请求头、环境变量或静态凭证。按以下优先级处理：
   - 优先：直接写入 Trae 全局 MCP 配置文件（macOS：`~/Library/Application Support/Trae CN/User/mcp.json`；Windows/Linux：Trae 用户数据目录下的 `User/mcp.json`），在 `mcpServers` 中加入 `aitoearn-cn`（或国际版 `aitoearn`）条目，值只含 `url`。**不要写 `~/.trae-cn/mcp.json`，它不会被加载。**
   - 无写权限，或写入后 设置 > MCP 列表仍未出现条目：改用官方方式，二选一——一键安装链接（把 README 中对应的 `trae-cn://trae.ai-ide/mcp-import?...` 链接发给用户，请用户粘贴到浏览器地址栏打开并在 TRAE 弹出的「手动配置」窗口确认），或请用户前往 **设置 > MCP > 添加 > 手动添加** 粘贴本包 `mcp.json` 中的对应条目。
   - 项目级（仅当前项目生效）：把本包 `mcp.json` 写入项目根目录 `.trae/mcp.json`，并请用户在 **设置 > MCP** 打开「启用项目级 MCP」开关。
3. 完全退出并重启 Trae。先确认 **设置 > MCP** 列表里出现 AiToEarn 条目（只看到配置文件内容不算成功），再对 AiToEarn 连接点击连接/认证，在浏览器完成 OAuth 授权；不要被动等待客户端弹出登录窗口。
4. 新建对话发送「列出可用的发布渠道」验证；只有真实返回工具结果才可报告成功。

如果当前 Trae 环境没有 OAuth 授权入口、无法保存或授权失败，明确报告“MCP 尚未配置完成”并停止。不要向用户索要 API Key，也不要改用旧的请求头配置。
