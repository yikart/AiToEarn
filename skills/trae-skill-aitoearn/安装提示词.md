# AiToEarn Trae 技能 安装指令

请帮我安装 AiToEarn（Trae 技能）。按下面步骤执行：

## 如何定位插件包

- 如果你是通过文件路径读取到这份文档的：插件包目录就是本文件所在的目录，直接使用它，不要去找其他路径。
- 如果你是在对话框里看到这段文字的：插件包默认位于本仓库 `skills/trae-skill-aitoearn` 目录（如果 skills 文件夹被移动或单独下载过，以实际路径为准）；如果该目录不存在，先向我询问实际路径再继续，不要使用其他来源的文件。

## 开始前检查

开始执行前先确认你能读写我的用户主目录（安装会写入 ~/.codex、~/.qwenworkcn、~/.dsh、~/.trae-cn、Library/Application Support 等位置，按本平台的步骤需要哪些就确认哪些）。如果确认没有权限，现在就告诉我，不要做到一半才失败。

第 0 步：请提供你的 AiToEarn API Key（获取方式：登录 aitoearn.cn → 设置 → API Key → 创建；如果给的是国际站 aitoearn.ai 的 Key 也请说明）。

## 安装步骤

技能（SKILL.md）和 MCP 连接**两部分都必须完成，缺一不可**；只复制技能目录不算安装完成。

1. 把插件包目录完整复制到 `~/.trae-cn/skills/aitoearn`（若已存在先备份再覆盖）。
2. 【MCP 配置 · 必须完成】读取包里的 `mcp.json`，把 `__AITOEARN_KEY__` 替换为我提供的 Key（国际站 Key 同时把 URL 换成 `https://aitoearn.ai/api/ai/agent/mcp`），再把 `mcpServers.aitoearn-cn` 合并进 `~/.trae-cn/mcp.json`（保留已有服务器，不要覆盖整个文件）；对 `~/Library/Application Support/Trae CN/User/mcp.json` 做同样合并（文件不存在则直接写入）。写完后读取这两个文件确认 `aitoearn-cn` 确实在里面，把确认结果告诉我。
3. 读取包里的 `skill-config.json`，把 `managedSkills.aitoearn` 合并进 `~/.trae-cn/skill-config.json`。

## MCP 手动兜底（自动配置失败时）

如果你因为权限等原因写不进那两个 mcp.json 文件，不要跳过，必须明确告诉我“MCP 还没配置”，然后指导我在 Trae 客户端里手动添加（菜单名称可能略有差异，以我的客户端实际显示为准）：

1. 打开 Trae → 左下角设置（齿轮图标）→ 找到「MCP」相关入口（可能叫 MCP 工具 / MCP Servers / 模型上下文协议）
2. 点「添加服务器 / 添加」，填写：
   - 名称：`aitoearn-cn`
   - 地址（URL）：`https://aitoearn.cn/api/ai/agent/mcp`（国际站 Key 用 `https://aitoearn.ai/api/ai/agent/mcp`）
   - 请求头（Headers）：添加一条，`X-Api-Key` = 我在第 0 步提供的 Key
3. 保存后告诉我完成了，再继续后面的重启验证步骤

## 安装完成后

提醒我必须完全退出并重新打开 Trae（不是关闭窗口），重启后新会话才会加载技能与 MCP 连接。

## 验证（这一步同时检验 MCP 是否配好）

在新会话里发送「列出可用的发布渠道」：
- 如果能列出渠道列表，说明技能与 MCP 都安装成功；
- 如果提示没有相关工具或找不到渠道，说明 MCP 没配好——请按上面的「如果第 2 步无法自动完成」指导我手动配置，配置完再次验证；绝对不允许只装技能就告诉我安装完成。


## 失败处理

- 任何一步失败，立即停止后续操作，用我能看懂的大白话告诉我卡在哪一步、缺什么，不要假装成功。
- 我不懂编程，也几乎不会用终端：**绝对不要给我终端命令、脚本或代码让我自己执行**。所有文件操作必须由你通过你自己的工具完成。
- 遇到系统权限拦截（例如 Operation not permitted / 权限被拒绝）时：先通过你所在应用自带的授权机制向我申请对应目录的访问权限，并提醒我在弹出的授权窗口里点「允许」；如果该应用没有授权机制、确实访问不了那些目录，直接明确告诉我“当前应用无法完成安装”，告诉我应该换用什么方式（例如改用官方安装器或该平台内置的插件市场），然后停止。
- 需要我在客户端里手动点击的步骤，给我一步一步的点击指引：点哪个菜单、选哪一项、填什么。
