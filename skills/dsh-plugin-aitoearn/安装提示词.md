# AiToEarnDeepSeek Harness 插件 安装指令

请帮我安装 AiToEarn（DeepSeek Harness 插件）。按下面步骤执行：

## 如何定位插件包

本插件不发布到 npm。先拉取源码：

```bash
git clone https://github.com/yikart/AiToEarn.git
```

插件包目录是仓库里的 `skills/dsh-plugin-aitoearn`，不要使用仓库根目录。

也可以直接安装这个子目录：

```bash
dsh plugin --profile desktop add "github:yikart/AiToEarn#path:/skills/dsh-plugin-aitoearn"
```

`desktop` 换成实际 profile 名。这条命令成功时，下面的手工复制可以跳过，直接做 OAuth 授权。

## 开始前检查

确认你能读写我的用户主目录（安装会写入 `~/.dsh` 等位置）。如果确认没有权限，现在就告诉我，不要做到一半才失败。

本插件使用 OAuth 授权，授权时会打开浏览器或让我输入设备码。

## 安装步骤

技能（SKILL.md）与 MCP 连接两部分都必须完成，缺一不可。

1. 把 `skills/dsh-plugin-aitoearn` 复制到 `~/.dsh/plugins/dsh-plugin-aitoearn`（若已存在先备份再覆盖）。
2. 编辑 `~/.dsh/profiles/desktop/package.json`：
   - 在 `dependencies` 里加
     `"dsh-plugin-aitoearn": "file:$HOME/.dsh/plugins/dsh-plugin-aitoearn"`
   - 在 `dsh.profile.bundles` 数组里追加 `"dsh-plugin-aitoearn"`
   - 若文件不存在，先创建最小骨架（name: dsh-profile-desktop, private: true,
     dependencies: {}, dsh.profile.bundles 含 @deepseek-ai/dsh-base 与 @deepseek-ai/dsh-web-app）。
   - 如果之前装过旧版 `dsh-plugin-aitoearn`，保留或移除都可以；两者同时存在时
     请确认没有重复的 `serverName: aitoearn` 冲突，必要时先移除旧插件条目。
3. 执行：
   `mkdir -p ~/.dsh/profiles/desktop/node_modules && ln -sfn ~/.dsh/plugins/dsh-plugin-aitoearn ~/.dsh/profiles/desktop/node_modules/dsh-plugin-aitoearn`
4. 若 `~/.dsh/profiles/desktop/cordis.patch.yml` 已存在，把本包 `cordis.patch.yml`
   的条目合并进去（id 重复则跳过）。保留 `site: cn`，鉴权固定走国内站。

## 安装完成后：OAuth 授权

1. 先提醒我**完全退出并重新打开 DeepSeek Harness**（不是关闭窗口）。
2. 重启后，由你执行：
   市场安装用 `~/.dsh/profiles/<profile>/node_modules/.bin/aitoearn login`（`<profile>` 与安装时的 `--profile` 相同）。
   手工复制到 `~/.dsh/plugins` 时用 `node ~/.dsh/plugins/dsh-plugin-aitoearn/scripts/aitoearn.mjs login`。
   脚本默认打开 https://aitoearn.cn 完成授权。
3. 脚本会输出授权链接，或「打开某网址并输入设备码」。请把链接 / 网址 / 设备码
   用大白话转达给我，并等我完成浏览器里的授权。
4. 授权成功后脚本会把令牌写入 `~/.aitoearn/oauth.json`（权限 600）并自动验证工具数量。
   **绝对不要把令牌内容打印给我或写进对话。**
5. 让我新开一个会话，然后发送「列出可用的发布渠道」验证。

## 验证

- 能正常返回渠道列表 → 技能与 MCP 都安装成功。
- 提示未授权、找不到工具或连接失败 → 说明 OAuth 还没完成，必须明确告诉我
  “OAuth 授权还没完成”，然后按下面「故障处理」处理，不允许只装技能就报安装完成。

## 故障处理

1. 运行 `~/.dsh/profiles/<profile>/node_modules/.bin/aitoearn status`（手工安装则把命令换成 `node ~/.dsh/plugins/dsh-plugin-aitoearn/scripts/aitoearn.mjs status`）
   查看是否已授权、令牌是否过期。
2. 如果报“未发现 OAuth 授权服务器”：说明部署尚未开启 OAuth。请告诉我这个结论，
   并询问我是否有授权端点 / 公共客户端 ID（对应 `AITOEARN_OAUTH_*` 环境变量）；
   不要自己编造端点。
3. 仍不通：告诉我“自动配置没成功”，建议改用官方「AiToEarn 全平台管理器」安装。

## 失败处理

- 任何一步失败，立即停止后续操作，用我能看懂的大白话告诉我卡在哪一步、缺什么，不要假装成功。
- 我不懂编程，也几乎不会用终端：**不要给我终端命令、脚本或代码让我自己执行**。
  所有文件操作和命令都由你通过你自己的工具完成。
- 遇到系统权限拦截时：先通过应用自带授权机制申请目录访问权限，并提醒我在弹窗点「允许」；
  如果确实访问不了，直接告诉我“当前应用无法完成安装”并给出替代方式，然后停止。
- 需要我在客户端里手动点击的步骤，给我一步一步的点击指引。
