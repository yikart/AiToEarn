# AiToEarn 豆包技能安装指令

请安装本目录的 AiToEarn 技能并配置 OAuth MCP 连接。

1. 在豆包导入本目录的技能。
2. 新建 HTTP MCP 连接器：中国版使用 `https://aitoearn.cn/api/ai/agent/mcp`，国际版使用 `https://aitoearn.ai/api/ai/agent/mcp`。不要填写认证请求头、静态凭证或旧配置。
3. **明确提示用户去连接器认证**：连接器创建后不会自动完成授权，用户需要在该连接器上点击连接/授权，在浏览器完成 OAuth 登录；然后重启豆包，新建对话发送「列出可用的发布渠道」验证。

如果没有 OAuth 授权入口、授权失败或工具未出现，明确报告 MCP 未连接并停止；不要向用户索要 API Key。
