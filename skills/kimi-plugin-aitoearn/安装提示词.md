# AiToEarn Kimi Work 插件安装指令

请安装本目录的 Kimi Work 插件与 OAuth MCP 连接。

1. 将插件目录导入或启用为个人插件。
2. 将 `mcp.json` 的服务器条目合并进 Kimi MCP 配置：中国版为 `https://aitoearn.cn/api/ai/agent/mcp`，国际版为 `https://aitoearn.ai/api/ai/agent/mcp`。不要添加认证请求头或静态凭证。
3. 完全重启 Kimi Work。**明确提示用户去 MCP 连接认证**：到 Kimi 的 MCP 连接管理页对 AiToEarn 连接发起认证，在浏览器完成 OAuth 授权；不要被动等待客户端弹出登录窗口。
4. 新会话发送「列出可用的发布渠道」验证；只有实际工具返回成功才能报告完成。

如无 OAuth 入口或授权失败，说明 MCP 尚未连接并停止；不要要求用户提供或保存 API Key。
